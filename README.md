# Nav: versões

Instaladores do **Nav**, um navegador leve para Mac (e, em breve, Windows).

Baixe a versão mais nova em **[Releases](../../releases/latest)**: o arquivo `.dmg` é o instalador do Mac.

O Nav instalado se atualiza sozinho a partir daqui. Cada versão vem assinada: o Nav só instala
atualizações com a assinatura certa.

Na primeira vez, o Mac pode avisar que o desenvolvedor não foi identificado: clique com o botão direito
no Nav → Abrir.
